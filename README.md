# Sistema de Cadastro de Vendedores

Sistema desenvolvido em Java utilizando Programação Orientada a Objetos.

## Funcionalidades

- Cadastro de até 10 vendedores
- Cadastro de nome, salário, vendas e faltas
- Cálculo de comissão
- Cálculo de desconto por faltas
- Cálculo do salário final
- Listagem dos vendedores em ordem alfabética
- Exibição dos dados utilizando JTable

## Tecnologias

- Java
- Programação Orientada a Objetos
- Java Swing

## Estrutura

- `App.java` — controla o menu, cadastro e listagem
- `Vendedor.java` — representa o vendedor e realiza os cálculos
